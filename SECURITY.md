# Security Policy

## Reporting a Vulnerability

Please do **not** open a public issue for security vulnerabilities.

Report privately via email to the repository owner, or use the GitHub
"Report a vulnerability" tab on this repository.

Please include:
- A description of the vulnerability and its impact
- Steps to reproduce (PoC if available)
- Affected versions

You will receive an acknowledgement within 48 hours and a detailed response
regarding the next steps.

## Supported Versions

Security fixes are applied to the default branch and maintained releases.

## Disclosure

We follow responsible disclosure: 90 days from the initial report before
public announcement, unless the issue is already publicly known.
